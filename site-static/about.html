Methodology

数据口径

当前版本优先验证三个问题：这家公司是否在中国有校招信号、是否能直达招聘信息页面、是否能找到可信的员工规模口径。

纳入规则

校招判断
优先采用官方校招页和官方招聘页，其次参考高校就业网和可信第三方招聘页。
员工规模
优先采用中国官网、年报、ESG 或中国业务页中的员工口径，其次保留全球口径。
时间窗
默认使用最近 12 个月的校招信号，避免将历史页面直接当成当前校招。
链接优先级
优先直达官方校招页，其次官方招聘页，再次是高校就业网或第三方招聘页。

页面说明

筛选方式
企业类型、行业分组、工作省份、链接状态可以组合使用，关键词支持模糊匹配。
详情页
单家公司详情会展示基础信息、备注和证据列表，便于复核来源。
部署方式
本站为纯静态页面，适合直接托管到 GitHub Pages。
